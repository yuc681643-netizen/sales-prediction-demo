# 数据获取与说明

本项目的数据来源记录为[阿里天池数据集 234704](https://tianchi.aliyun.com/dataset/234704)。从来源获取 `data.xlsx`，放在本目录，即项目根目录下的 `data/data.xlsx`；工作表名称为 `data`。

本次检查使用的原始文件有 24,037 行、24 列。仅 499 条同时具有价格和销量文本，筛除 13 条浏览人数记录后得到 486 条付款人数记录、464 个不同商品。完整字段说明见项目根目录的 README。

数据统计周期和再分发许可尚未核实，因此 GitHub 发布包不包含原始工作簿、清洗后的逐条数据或逐条测试预测。它们可在获得数据后通过 Notebook 本地生成。发布包保留指标汇总和图表用于展示本次实验。

目标 `payment_display` 是付款人数展示值；“万”换算为 10,000 倍，带“+”的值是近似下界。当前目标不能解释为精确月销量，也没有用于验证未来月份预测的标签。
